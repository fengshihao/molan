# 流程图测试

## 宽图 TD

```mermaid
flowchart TD
  A[用户提交订单请求] --> B[订单服务校验参数]
  B --> C{库存是否充足?}
  C -->|库存不足| D[返回失败并提示补货]
  C -->|库存充足| E[锁定库存并生成预扣记录]
  E --> F[调用支付网关创建支付单]
  F --> G{支付是否成功?}
  G -->|失败| H[释放库存并通知用户]
  G -->|成功| I[通知仓储系统拣货发货]
  I --> J[发送订单完成通知给用户]
```

flowchart LR
