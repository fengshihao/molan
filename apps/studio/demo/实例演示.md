## 下单时序

```mermaid
sequenceDiagram
  participant U as 用户
  participant App as 客户端
  participant GW as API 网关
  participant Order as 订单服务
  participant Stock as 库存服务
  participant Pay as 支付网关

  U->>App: 提交订单
  App->>GW: POST /orders
  GW->>Order: 创建订单
  Order->>Stock: 预留库存
  alt 库存不足
    Stock-->>Order: 预留失败
    Order-->>App: 返回失败
  else 库存充足
    Stock-->>Order: 预留成功
    Order->>Pay: 创建支付单
    Pay-->>Order: 支付成功
    Order-->>GW: 订单已确认
    GW-->>App: 下单成功
  end
```

## 履约流程

```mermaid
flowchart TD
  A[用户提交订单请求] --> B[订单服务校验参数]
  B --> C{库存是否充足?}
  C -->|库存不足| D[返回失败并提示补货]
  C -->|库存充足| E[锁定库存并生成预扣记录]
  E --> F[调用支付网关创建支付单]
  F --> G{支付是否成功?}
  G -->|失败| H[释放库存并通知用户]
  G -->|成功| I[通知仓储系统拣货发货]
  I --> J[发送订单完成通知给用户]
```
