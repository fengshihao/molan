# Changelog

## Unreleased

## 0.1.32

- 选中文字后可用 `Cmd/Ctrl+B` 加粗、`Cmd/Ctrl+I` 斜体、`Cmd/Ctrl+K` 加链接（预览与编辑都可用）

## 0.1.31

- 预览里可以直接勾选待办：点 `- [ ]` 写成 `[x]`，再点改回，不必先进入编辑

## 0.1.30

- 反馈按钮挪到顶栏最右侧（字号 / 纸面旁），避免窄窗时被裁切看不到

## 0.1.29

- 顶栏新增「反馈」：站内填表后预填打开 GitHub Issue；命令面板「墨览: 反馈问题」
- 官网 / README / 商店说明补齐 Issues 入口

## 0.1.27

- 纸面新增青石、薄雾、朱砂三套预设
- 纸面设置增加色调微调：亮度、对比、强调色（按主题分别记住）；拖动时不狂刷流程图

## 0.1.26

- 修复 Mac 下 `Cmd+P` 被当成打印：VS Code / Cursor 中改为交给 Quick Open；浏览器里按平台区分 ⌘ / Ctrl

## 0.1.25

- 菜单拆到三处：行首「+」插块，选中出格式条，顶栏撤销 / 重做
- 格式条补删除线和行内代码；「+」补标题、列表、引用、分割线
- 预览改格式或插入也能撤销重做，不必先进入编辑
- 保存按钮只在兼容模式（选文件夹）出现
- 「问这一节」只在工作台出现，墨览不再显示

## 0.1.24

- 选中文字在预览和编辑都会出格式条（加粗 / 斜体 / 链接），样式与行首加号一致
- 大纲按钮改到标题左侧，不再和行首加号重叠
- 本机工作室默认监听局域网，可用本机 IP 访问

## 0.1.23

- 内联流程图预览也 vectorize HTML 标签，修复 Windows 上文字被遮挡溢出

## 0.1.22

- 加号插入流程图后立刻显示预览，不再把源码留在图末尾
- 语法错误不再把错误卡堆到页面底部；渲染改到离屏沙箱，避免把图压扁

## 0.1.21

- 修复大流程图灯箱打开后停在半清晰：按 SVG 真实尺寸缩放，去掉 CSS scale 合成层
- 灯箱/编辑遮罩的毛玻璃改到背景层，避免流程图被栅格成 1x
- 克隆进灯箱时重写 SVG id，并把 HTML 标签换成矢量文字

## 0.1.20

- 查看原文支持直接编辑 Markdown，修改会同步预览并标记未保存
- 预览与查看原文切换时保持阅读位置；关闭原文后预览不再跳回开头
- 切换编辑/预览时自动关闭原文遮罩，避免按钮无反应
- 修复 molan-host TypeScript 编译错误，恢复 `pnpm vscode:molan` 与 CI 构建

## 0.1.19

- 排版菜单打开更快：字体列表默认收起，点「字体」再展开并加载预览，不再卡住弹出动效

## 0.1.18

- 修复 VS Code / Cursor 安装后打开 Markdown 一直转圈：把 `molan-host` 打进扩展包
- 编译扩展时显式带上 `zod`，缺依赖会先自动安装，避免 pnpm 隔离导致找不到
- 复制原文、流程图代码、代码块在 webview 无剪贴板权限时降级；流程图源码可从 Markdown 恢复
- 导出菜单可用 Esc 关闭；主要功能按钮增加自动化回归

## 0.1.17

- 修复复制流程图：Mermaid HTML 标签不再污染 canvas，PNG 可正常写入剪贴板

## 0.1.16

- 顶栏增加导出：PDF（系统浏览器打印存盘；Cursor 内置窗口改为下载可打印 HTML，避免崩溃）与 PNG 图片
- 修正 PDF 分页：长代码/表格可跨页，流程图缩进单页
- 查看原文图标改为代码括号，导出改为独立菜单

## 0.1.15

- 流程图编辑页右侧预览可就地滚轮 / 按钮缩放，不必再开灯箱
- 观看灯箱放大后可直接进入流程图编辑
- 顶栏改为「查看原文」：原文不再挡住大纲，点击标题可跳到对应源码
- 工作室内置样例改为框架图与时序图
- 预览「+」插入后切到编辑时保持滚动位置和焦点
- 修复代码块展开编辑时源码不可读、切模式跳动
- 流程图改为独立编辑对话框，预览态也可改源码并插入模板片段

## 0.1.14

- 工作室侧栏直接列出一份内置样例，去掉「试读示例」按钮
- 预览和编辑切换时停在当前阅读位置，不再跳回开头
- 编辑态代码块与预览同高，避免切模式时页面跟着跳
- 大纲改为 Vditor 左侧栏，不再做成浮动菜单；开关按钮固定漂在阅读区左上角，不占正文、不随滚动走；文档更新后大纲跟着刷新
- 大纲改为层级目录图标，编辑方式改为叠页图标，避免和「编辑 / 对齐」混淆
- 编辑时去掉全屏和工具栏字数
- 预览和编辑时，悬停块左侧出现「+」，可插入标题、列表、代码、表格、公式、流程图等（不必手写 Markdown）
- 表格：插入时可选择行列数（不再固定 3×3）；编辑时选中单元格可增删行列；工具栏表格按钮在 Vditor 灰掉时仍可点开尺寸网格
- 图片改为插入网络地址，不再从本地文件拷到文档旁边
- 流程图预览与灯箱尺寸对齐预览态；工具栏悬停或聚焦时才显示
- VS Code 顶栏去掉「已同步 / 未保存」：标签页圆点已经表示脏状态，底栏只留字数
