## 立刻用

```bash
git clone https://github.com/fengshihao/molan.git
cd molan
./molan            # 打开本机网页
./molan 试读       # 试读工作室
./molan 安装       # 安装 Cursor / VS Code 扩展
./molan 帮助
```

网上试读：[GitHub Pages](https://fengshihao.github.io/molan/try/) · [molan.guoyoutech.cn](https://molan.guoyoutech.cn/)  
扩展：`fengshihao.molan-markdown`（[Open VSX](https://open-vsx.org/extension/fengshihao/molan-markdown) · [Marketplace](https://marketplace.visualstudio.com/items?itemName=fengshihao.molan-markdown)）

## 一句话贡献（推荐）

打开 Cursor，把意图告诉 AI（完整提示在 [`docs/ai/START.md`](docs/ai/START.md)）。**克隆仓库、读说明、改代码、跑检查都让 AI 做**；你只负责说要什么、看结果。

验收：

```bash
./molan 检查       # 必须通过
./molan            # 肉眼看官网
```

两步说明：https://fengshihao.github.io/molan/docs/
