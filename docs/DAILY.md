# 每日一小版

从 0.1.31 起，每个版本只做下面队列里的下一项，做完就发。优先改打开、阅读、轻量编辑这些每天都会碰到的操作。

做下一项前先看本文件：勾掉已发版本，只实现「下一项」。

## 队列

- [x] **0.1.31** 预览里直接勾选待办。点 `- [ ]` 写成 `[x]`，再点改回，不必先进入编辑。可撤销。
- [ ] **下一项** 加粗、斜体、链接快捷键。选中后 `Cmd/Ctrl+B`、`Cmd/Ctrl+I`、`Cmd/Ctrl+K`，预览和编辑都生效。
- [ ] 一个键切换阅读和编辑。`Cmd/Ctrl+E` 对应顶栏按钮，切过去停在当前段落。
- [ ] 查找里加上替换。现有查找栏加替换、替换当前、全部替换。
- [ ] 双击正文进入编辑。双击某一段就切到编辑，光标落在这一段。
- [ ] 文内标题链接滚到对应位置。扩展里点 `[见下文](#安装)` 滚到那个标题。
- [ ] 记住每份文档的阅读位置。关掉再打开，停在上次看到的地方。
- [ ] 粘贴截图就插入图片。剪贴板图片存到文档旁边，正文写入相对路径。扩展先做，工作室再对齐。
- [ ] 大纲用键盘打开并跳转。`Cmd/Ctrl+Shift+O` 打开大纲，上下键选择，回车跳转。
- [ ] 预览里复制保留 Markdown。选中一段复制出去仍是 `**加粗**`、列表和链接。
- [ ] 顶栏按钮标上快捷键。编辑、查找、大纲、导出的提示里写上对应按键。
- [ ] 表格里按 Tab 跳到下一格。`Shift+Tab` 向左，最后一格再 Tab 就加一行。
