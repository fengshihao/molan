# 每日一小版

从 0.1.31 起，每个版本只做下面队列里的下一项，做完就发。优先改打开、阅读、轻量编辑这些每天都会碰到的操作。

做下一项前先看本文件：勾掉已发版本，只实现「下一项」。功能合并到 `main` 后调高 `apps/vscode-molan/package.json` 版本，在 `main` 执行 **`./molan release`**（说明由 commit 汇总，CI 出 GitHub Release）。

## 队列

- [x] **0.1.31** 预览里直接勾选待办。点 `- [ ]` 写成 `[x]`，再点改回，不必先进入编辑。可撤销。
- [x] **0.1.32** 加粗、斜体、链接快捷键。选中后 `Cmd/Ctrl+B`、`Cmd/Ctrl+I`、`Cmd/Ctrl+K`，预览和编辑都生效。
- [x] **0.1.33** 一个键切换阅读和编辑。`Cmd/Ctrl+E` 对应顶栏按钮，切过去停在当前段落。
- [x] **0.1.34** 修原文面板改完切预览显示旧内容；表格工具栏不再挡住第一行。
- [x] **0.1.35** 查找里加上替换。现有查找栏加替换、替换当前、全部替换。
- [x] **0.1.36** 双击正文进入编辑。双击某一段就切到编辑，光标落在这一段。
- [x] **0.1.37** 文内标题链接滚到对应位置。扩展里点 `[见下文](#安装)` 滚到那个标题。
- [x] **0.1.38** 记住每份文档的阅读位置。关掉再打开，停在上次看到的地方。
- [x] **0.1.39** 粘贴截图就插入图片。剪贴板图片存到文档旁边，正文写入相对路径。扩展先做，工作室再对齐。
- [x] **0.1.40** 大纲用键盘打开并跳转。`Cmd/Ctrl+Shift+O` 打开大纲，上下键选择，回车跳转。
- [x] **0.1.41** 导出可选无底；流程图工具条悬停出现在卡片右上角，不再盖住图。
- [x] **0.1.42** 修好两个阅读/编辑问题：`pdf-to-mp3` 不再被当成音频；VS Code 编辑模式下 `Cmd/Ctrl+X` 可以剪切。
- [x] **0.1.43** 预览里复制保留 Markdown。选中一段复制出去仍是 `**加粗**`、列表和链接。
- [x] **0.1.44** 顶栏按钮标上快捷键。编辑、查找、大纲、导出的提示里写上对应按键。
- [x] **0.1.45** 表格里按 Tab 跳到下一格。`Shift+Tab` 向左，最后一格再 Tab 就加一行。
- [x] **0.1.46** 预览里打开本地文件链接。点 `a/b/c.go#L516` 在编辑器中打开并跳到对应行。
- [x] **0.1.47** 导出网页时弹出保存位置。编辑器里不能直接打印，保存框把网页写到选定路径。
- [x] **0.1.48** 预览双击选中段落；`Alt+双击` 进入编辑。预览里复制表格时贴回 pipe 表源码，而非 TSV。

## 下一波队列（0.1.49 起，一天一项）

原则照旧：只实现队首一项 → `./molan check`（改编辑器加 `./molan e2e`）→ 合并 `main` → bump 版本 → `./molan release`。  
**刻意不做**：`⌘L` 选段、表格单行复制、阅读位置扩展↔try、默认预览/记忆模式——快捷键和选项尽量少。

- [x] **0.1.49 — 大纲跟随当前阅读节（提前）**  
  **已有**：`⌘⇧O` 打开大纲、回车跳转（0.1.40）。  
  **要做**：滚动预览时大纲里当前 `h1–h6` 高亮；点大纲仍跳转。

- [x] **0.1.50 — 流程图编辑时预览缩放/平移不闪回**

  **要做**：重绘后保留用户缩放与拖动；仅打开对话框或点「适应」时重置。

- [ ] **0.1.51 — 阅读手势提示（原交互提示）**

- [ ] **0.1.52 — 预览拖选代码 ⌘C 带围栏**

- [ ] **0.1.53 — 预览复制公式贴回 TeX**
