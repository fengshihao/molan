# 扩展：墨览 Markdown

在 Cursor 或 VS Code 中安装 **墨览 Markdown**（`fengshihao.molan-markdown`），打开 `.md` / `.markdown` / `.mdown` / `.mdx` 即可。

- Open VSX：https://open-vsx.org/extension/fengshihao/molan-markdown  
- Marketplace：https://marketplace.visualstudio.com/items?itemName=fengshihao.molan-markdown  

打开即预览；点「编辑」再改；`Cmd/Ctrl+S` 写回原文件。未改动关闭不会询问保存。

纸面、排版、Mermaid、导出等说明见商店页与 https://molan.guoyoutech.cn/extension.html  

源码一期仍在 DesignWeave 的 `apps/vscode-molan`。
