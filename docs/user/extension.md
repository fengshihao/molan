# 扩展：墨览 Markdown

在 Cursor 或 VS Code 中安装 **墨览 Markdown**（`fengshihao.molan-markdown`），打开 `.md` / `.markdown` / `.mdown` / `.mdx` 即可。

- Open VSX：https://open-vsx.org/extension/fengshihao/molan-markdown  
- Marketplace：https://marketplace.visualstudio.com/items?itemName=fengshihao.molan-markdown  

打开即预览，预览里可以直接勾选任务；选中文字后可用 `Cmd/Ctrl+B` / `I` / `K` 加粗、斜体、加链接；`Cmd/Ctrl+E` 切换阅读和编辑（也可 `Alt/Option+双击` 某一段）；双击段落会选中该段便于复制；`Cmd/Ctrl+S` 写回原文件。未改动关闭不会询问保存。

纸面、排版、Mermaid、导出等说明见商店页与 https://fengshihao.github.io/molan/try/extension.html

功能统计只在编辑器打开了「使用情况」遥测时发送，内容是功能名，不含路径和正文。设置项 `molan.usageTelemetry` 可单独关掉。  

源码一期仍在 DesignWeave 的 `apps/vscode-molan`。
