# Security Policy

## Supported versions

The VS Code / Cursor extension published as `fengshihao.molan-markdown` and the static studio at `molan.guoyoutech.cn` / GitHub Pages.

## Reporting a vulnerability

Please **do not** open a public issue with exploit details.

Email the repository owner via GitHub (fengshihao) private advisory, or open a GitHub Security Advisory on this repository:

https://github.com/fengshihao/molan/security/advisories/new

Include: affected surface (extension / studio / site), version or commit, impact, and reproduction if safe.

We will acknowledge and work on a fix as soon as practical.
